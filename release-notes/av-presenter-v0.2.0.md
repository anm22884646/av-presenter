AV Presenter 0.2.0 — Windows x64 testing build

下載 `AV-Presenter-Windows-x64-0.2.0.zip`，完整解壓後執行 `AV Presenter.exe`。不需 Node.js，請保留所有相鄰檔案。

此版本加入：
- English、日本語、正體中文、简体中文介面選單。
- 保存文字、時鐘、倒數的樣式、字體大小、位置、背景，以及 Preview / Program、媒體與輸出螢幕。
- 勾選啟動還原後，自動儲存變更並還原播放與原先啟用的輸出。
- 可選登入 Windows 後自動啟動。

展覽設定：先 TAKE 展示內容、啟動輸出，再啟用還原與登入自動啟動。請將應用程式及媒體放在固定位置。

倒數從保存的剩餘時間继续，不計關機期間；影片從頭開始播放。Windows 自動啟動需要登入。

此為未簽章的預發測試版。TypeScript 編譯與 10 項狀態／儲存／語言測試通過；Windows 實機、雙螢幕及登入自動啟動仍需驗證。完整驗收步驟見包內 `WINDOWS-VALIDATION.md`。
